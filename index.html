Belum punya API key? Cara bikin dalam 5 menit
1. Buka console.cloud.google.com, bikin project baru (nama bebas).
2. Menu "APIs & Services" → "Library" → cari YouTube Data API v3 → Enable.
3. Menu "Credentials" → "Create Credentials" → "API Key". Key langsung muncul, tinggal disalin.
4. Opsional tapi disarankan, klik "Restrict Key", batasi ke YouTube Data API v3 saja, supaya key tidak disalahgunakan kalau bocor.
5. Video ID diambil dari URL live-nya begitu sudah live di YouTube Studio, formatnya youtube.com/watch?v=ID_VIDEO.
Key ini cuma dipakai di browser ini, tidak dikirim atau disimpan ke server manapun selain langsung ke API Google.
Mode ini buat jaga-jaga kalau koneksi API bermasalah pas hari H. Kurator tinggal salin isi panel live chat YouTube Studio lalu tempel di sini, bisa dipakai berkali-kali selama acara.
